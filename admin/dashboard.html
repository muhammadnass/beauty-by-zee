Set Product Prices
Prices are synced to all customers via Supabase, or saved locally if Supabase is not set up.

☁️ Supabase Cloud Sync

To sync prices to ALL customers globally, set up Supabase (free). Without it, prices are saved to this browser only.

1. Go to supabase.com → create a free project.

2. In SQL Editor, run:

CREATE TABLE prices (id INTEGER PRIMARY KEY, price NUMERIC DEFAULT 0, updated_at TIMESTAMPTZ DEFAULT NOW()); ALTER TABLE prices ENABLE ROW LEVEL SECURITY; CREATE POLICY "Public read" ON prices FOR SELECT USING (true); CREATE POLICY "Admin write" ON prices FOR ALL USING (true);

3. Copy your Project URL and anon key from Settings → API.

4. Open js/supabase.js and paste them into SUPABASE_URL and SUPABASE_KEY.

5. Re-deploy. Prices will now sync to every visitor! ✅

💡 Set price to 0 to show "Price on request" to customers.
